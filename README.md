# 🌍 Global Sales Performance & Profitability Dashboard

## 📌 Project Overview

The **Global Sales Performance & Profitability Dashboard** is a professional Tableau Business Intelligence project developed to analyze worldwide sales trends, profitability, customer behavior, and regional business performance.

This dashboard helps organizations monitor key business KPIs, identify profitable regions and product categories, and support strategic decision-making using interactive visual analytics.


# 🎯 Project Objectives

- Analyze global sales performance across regions
- Monitor profit and profitability trends
- Identify top-performing products and countries
- Track monthly sales growth
- Analyze customer segment contribution
- Evaluate the impact of discounts on profitability
- Build an interactive executive-level dashboard
